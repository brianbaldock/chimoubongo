# Chimoubongo

A website for a town in the Mauricie that does not exist.

Bilingual, static, no build step, no dependencies, no JavaScript.

- `index.html` — French (Québécois), default
- `en.html` — English (Canadian)
- `assets/logo.png`

Everything is inline: CSS, the hand-drawn SVG map, the attraction icons.
Open either file in a browser and it works.

## Fiction notice

Chimoubongo is invented. Shawinigan, Grandes-Piles, Saint-Roch-de-Mékinac,
Lac-Édouard, La Tuque, the Saint-Maurice river and the Parc national de la
Mauricie are all real and worth your time. The town between them is not.
